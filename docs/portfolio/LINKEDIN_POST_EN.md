# LinkedIn post - English

🚀 New portfolio project: **Huawei Cloud FinOps & Intelligent Capacity
Optimization Platform**

Cloud optimization should not mean reducing cost at the expense of reliability.
This project brings financial and engineering signals into the same
decision loop.

The platform combines Huawei Cloud cost analysis, budgets, allocation tags,
CCE/AOM capacity evidence, anomaly detection, forecasting, and explainable
rightsizing. Every recommendation includes observed evidence, confidence, risk,
estimated savings, and a reversible action. The executive savings total is
conservative: incompatible opportunities for the same resource are never
double-counted.

📊 Reproducible demo results:

- $6,133.36 monthly amortized cloud cost
- $1,520.70 conservative monthly savings opportunity
- $18,248.40 annualized opportunity
- 97.43% cost allocation coverage
- 100% budget coverage
- 21 prioritized decisions and 2 detected anomalies

The repository includes a Python/FastAPI analytics service, Docker,
Prometheus/Grafana control tower, Kubernetes + Kustomize, Helm, Terraform for
Huawei Cloud CCE/OBS/SMN, OPA policies, 43 core tests, CodeQL, and Trivy.

Built as a read-only decision platform: no resource is stopped, resized,
deleted, or purchased without explicit owner approval and rollback evidence.
